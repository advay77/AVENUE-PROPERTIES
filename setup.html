Connect the live features

This page is not linked from the public site and is marked noindex. Use it to test the alert channels and the Google Reviews connection, then paste the generated settings into assets/js/config.js. Nothing typed here is saved to the server — the values stay in this browser until you copy them across.

Open this over http, not from the file system. Browsers block cross-site requests from file:// pages, so test alerts will fail until the site is served from a web address (or localhost).

1 · Live visitor & enquiry alerts

Fill in any one channel. Alerts go to every channel you configure. All of these are free — no WhatsApp Business API, no monthly fee.

Message @BotFather → /newbot for the token. Then message your new bot once, open api.telegram.org/bot<TOKEN>/getUpdates and copy the chat.id.

A relay keeps the bot token off the public page. README.md has a free Cloudflare Worker you can paste in and deploy in about five minutes. When a relay is set, nothing else is called from the browser.

2 · Google reviews

Three values, all from the client’s Google Business Profile. The “Write a Review” button works as soon as the Place ID is in — the API key is only needed to pull the live rating and review text onto the page.

Find a Place ID

Restrict the key. In Google Cloud, set Application restrictions → HTTP referrers and add the live domain. An unrestricted Places key can be used by anyone who views the page source, and it bills to the client’s account.

Google returns at most five reviews through its API, and chooses which five. That is Google’s limit, not the site’s. The “Read every review on Google” link covers the rest.

4 · Enquiries saved in this browser

While no channel is connected, every enquiry is kept here so nothing is lost. This is a safety net for the demo period, not a CRM — it lives only in this browser.

5 · Before going live

  • Replace the demo listings in assets/js/data.js with real inventory
  • Swap the placeholder photography for the client’s own photographs
  • Set demoMode: false in config.js to drop the “Sample listing” badges
  • Add the social profile links in config.js (blank ones are hidden automatically)
  • Connect one alert channel and send a real test from a phone
  • Add the Google Place ID so “Write a Review” goes live
  • Write real Privacy Policy, Terms and Disclaimer pages — the footer links are placeholders
  • Publish on a real domain over HTTPS; alerts and Google both need it
